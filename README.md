Entry for the [Worst Superpower](https://make.fun/c/u-suroto-worst-superpower-461dcdbe) competition on make.fun: the most useless superpower in one line.

## The entry

> I can shoot lasers from my eyes, but only the kind that opens my neighbour's garage door.

## How it works

`main.ts` writes the one-liner to `/output/entry.txt`. Nothing else: no network, no dependencies, no input data. Run it with Node 22.18+:

```sh
node main.ts
```
